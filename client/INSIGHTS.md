# Client insights

- [2026-09-21] **Codebase Patterns**: Review-run severity filters belong beside the run's own findings; a page-level aggregate cannot prove that a pill count matches the cards below it. Evidence: `client/src/app/repos/[repoId]/pulls/[number]/_components/ReviewRunAccordion/ReviewRunAccordion.tsx:65`.
- [2026-09-21] **Decisions**: PR-list finding previews are read-only hover surfaces, while Accept/Dismiss remains on the PR detail FindingCard. Evidence: `client/src/app/repos/[repoId]/pulls/_components/FindingsPopover/FindingsPopover.tsx:14`.
- [2026-09-21] **Recurring Errors & Fixes**: Enriched PR-list fields are cached separately from review records, so a completed review must invalidate the `pulls` query or the list keeps stale score/findings. Evidence: `client/src/lib/hooks/reviews.ts:143`.
- [2026-09-27] **Recurring Errors & Fixes**: In interactive agent configuration, `linked` and `enabled` are different states. Render the checkbox from `link.enabled`, persist the explicit boolean from the checkbox callback, and test both the visual state and the saved state after reload. Evidence: `client/src/app/agents/[id]/_components/AgentEditor/_components/SkillsTab/SkillsTab.tsx:18-21`.
- [2026-09-27] **UI Interaction Contract**: A design screenshot's actions are part of the feature contract. Skills Versions must expose a Diff action, and mutations must expose pending/error feedback; a static version list or silent mutation failure is incomplete. Evidence: `client/src/app/skills/page.tsx:32-34`.
- [2026-09-27] **Import Flow**: File import should call the server preview mutation before showing the confirmation editor; saving an imported skill must call the import endpoint so its `extracted` provenance is preserved. ZIP handling reads markdown bytes only and never executes entries. Evidence: `client/src/app/skills/page.tsx:22-30` and `client/src/lib/skills-import.ts`.
- [2026-09-27] **Diff correctness**: Do not compare version text with index-only replacement logic or escaped literal newline strings. Use a real line splitter and deterministic added/removed/context rows so changed lines show both sides. Evidence: `client/src/lib/skill-diff.ts`.
- [2026-09-27] **Resource bounds**: Client-side file parsing and diff rendering must reject oversized input before allocating unbounded buffers or DP matrices; return an explicit safe fallback instead. Evidence: `client/src/lib/skills-import.ts` and `client/src/lib/skill-diff.ts`.
- [2026-09-27] **Streaming decompression**: For ZIP imports, validate expanded bytes during `DecompressionStream` reads; checking only compressed size or checking after `arrayBuffer()` still permits a decompression bomb to allocate excessive memory. Evidence: `client/src/lib/skills-import.ts:9-33`.
